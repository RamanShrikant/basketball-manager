PATCH 28 - Surgical offseason/free-agency + draft-trade stability patch

Scope
- Fixes Year 2+ free agency opening with stale prior-year FA state instead of the current offseason's expired-contract / options / rights cleanup.
- Adds season-year stamps to free-agency state and pre-free-agency completion flags so 2027 FA state cannot be reused for 2028.
- Adds a backend pre-FA audit that blocks FA Day 1 if standard-roster players still have no active contract, unresolved options, or expired salary slots for the target season.
- Preserves and regenerates autogenerated draft-class secondary positions.
- Null-proofs resolved draft-pick ownership updates so draft-day accepted trades do not crash on null draft-order rows.
- Keeps League Events visible after RFA matches by rendering from durable fullActionLog-derived summary entries before volatile latestResults.
- Removes the Calendar modal's single-game "Simulate this game" button.
- Aligns Power Rankings with the same projected offseason roster context used by offseason trade logic.
- Blocks mega star-sale logic for teams ranked top 12 by healthy roster strength, protecting strong teams from injury-driven down-year fire sales.

Notes
- Existing old autogenerated upcoming draft previews are invalidated by schema version and will regenerate with secondary positions.
- Custom uploaded draft classes are not changed by this patch.
- If a broken save already has 2028 FA open with stale 2027 leftovers, the safest in-game repair path is to restart that offseason step after applying the patch so the current-year options/rights/expired-contract cleanup can run.
